# Known costs

Each of these is settled. What remains is a cost the decision lands on an implementation, or a limit of the suite, and a second implementation is told here rather than left to find it.

- **The text decision is cheap in Swift and dear elsewhere.** Grapheme-cluster counting and canonical equivalence come with the platform in Swift and are a library obligation in most other languages; the decision stands, and the cost lands on implementations unevenly.
- **The suite covers the constructs, the vocabulary, the encodings and the objects, and a few rules no case can hold.** Every construct, the naming and leaving rules, the envelope, the boundary settlements, every standard procedure, what a binary reader must refuse and what a build writes down for each operation are held as cases, and each page names its own under *Cases*. The rest no case can hold:
  - Cancellation needs a host with a lever, which a data case is not, so stopping is held only by tests inside the Swift implementation.
  - The concurrency grant needs a host that leaves `std.concurrent` out of the link, and a runner links the standard vocabulary for every case.
  - A case writes the stage a document is refused at and no place, so which spot a refusal names, under [checking](checking.md), and the line and column a text refusal names, under [encodings](encoding.md), are held only by tests inside the implementation. The sentence beside the place is the implementation's, and two implementations agreeing on every case may still say the reason in different words.
  - What a procedure the host answers declares it sends is the host's code, and a case writes none of it, so a send of the host's reaching a `private` declaration, or one taking a parameter in place, is refused under [procedures](procedure.md) and held only by tests inside the implementation.
  - A case's vocabulary always stands as a document, so a `private` procedure the host answers in a module the host assembled with no document, refused where the module is made under [procedures](procedure.md), is held only by tests inside the implementation.
  - A case starts one run of its image, so that every run starts each module variable at its settled value, under [documents](document.md), is held only by tests inside the implementation.
  - A fraction that is not a number arises only from a host's own procedure, and what a case's vocabulary answers is written in a document's spelling, which has none, so that it is not equal to itself, under [values](value.md), is held only by tests inside the implementation.
  - A runner keys every object it compiles and every case's document is written down, so an object leaning on one with no key, or holding a closure written by a document nobody wrote down or a box of the run that made it, is not written under [objects](object.md), and that is held only by tests inside the implementation.
  - A writer handed a value no reader produces, one deeper than the bound or holding infinity or NaN, refuses, and a case hands a writer only what a reader read, so those refusals are held only by tests inside the implementation.
  - A document at the nesting bound fits in no case, since the case's own records stand around it and add to its depth, so a reader and a writer taking one 128 deep is held only by tests inside the implementation.
- **Two equivalences coexist, and the border is drawn.** Values compare as a person reads. `equal`, `contains`, ordering and `count` all read text under canonical equivalence, stated under the value model. Names are matched as bytes and held to NFC at `load`, so a document cannot declare `é` one way and reference it the other. What remains here is only the cost: an implementation whose platform compares by code unit owes a library the difference.
- **A run's values have no bound, and an implementation walks them on its own stack.** The nesting bound is the wire's, under [encodings](encoding.md), and a running program builds deeper values than any document. An implementation whose comparison, rendering or release of a value recurses meets a depth there that no document brought, and owes either a walk on a stack of its own or a host that stops the run; the language refuses nothing there.
